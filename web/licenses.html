Release scope note

Cargo.lock also lists dependencies for the command-line and terminal programs, plus build-time-only proc-macro crates. Those crates are not compiled into or distributed with the current browser WASM assets and are therefore not listed as shipped browser components.

The local license files are verbatim copies of the upstream license files. The two Apache-2.0 copies differ only in whether the upstream file includes the optional “How to apply” appendix. The MIT copies differ only in their upstream copyright lines.
